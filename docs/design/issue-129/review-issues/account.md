## 共通の進め方・制約

- 本Issueは**調査・比較・要件整理**が成果物。修正案は採用決定ではない。採用／見送り／保留と理由を記録する。
- 観測済みの課題、コードからの確認事項、未検証の仮説を区別する。未撮影箇所は実画面を確認してから判断する。
- #129で選定した「B スレートグレー」を前提にする。配色・デザインの再選定は行わない。
- 実装する場合は#130との担当範囲を照合し、必要に応じて別実装Issueへ切り出す。実装・DB変更・本番操作をこの起票だけで承認済みにしない。
- AGENTS.mdと現在のコード・schema・Specを優先。既存Rails/ERB/Bootstrap/Turbo/Stimulus/importmapを維持し、新Gem/npm・AI API・Google認証を前提にしない。
- current_userによるデータ分離、Markdown無害化、CSRF、入力検証・保存前確認を維持する。簡略化のために弱めない。
- 架空データを使用し、秘密値・本番データ・認証情報をIssue・画像・ログへ記載しない。
- 実装時は1 Issue = 1ブランチ = 1PR。ユーザーの指示に従い、実装→対象テスト→全体テスト→RuboCop→git diff→結果報告で停止。commit/push/PRは別指示、マージはユーザーが行う。
