確認できること

  1. Tabキーで、入力欄・タグ解除・ボタンを順に移動できます。
  2. タイトルを空にして保存すると、エラーと入力位置の案内を確認できます。
  3. 「保存を試す」で約3秒間の送信中表示になります。
  4. 「保存失敗を表示」で、入力・選択中タグが残ることを確認できます。

フォームの値はこのページ内だけで扱います。サーバー送信・DB保存・ブラウザへの永続保存はありません。

上部の「フォーカス」列は輪郭を固定表示した見本です。実際のキーボードフォーカスは、この操作欄とほかの操作可能な要素で試せます。

送信中の入力欄・タグのロックは状態を確認するための見本です。実アプリでの送信イベント・入力保持の詳細は#136／#143で確定します。
