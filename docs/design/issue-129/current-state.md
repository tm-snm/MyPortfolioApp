## 維持する良い点

- トップに架空の具体例があり、サービスの出力を理解しやすい。
- コピー成功後に「外部AIへ貼り付け→回答をコピー→戻る」を明示している。
- AI解析時は自動保存せず、確認・編集できる。形式が異なる場合の手修正も案内される。
- 空入力エラーは入力欄に関連付けられ、フォーカスも移る。
- 送信中はボタンの文言が変わり、保存・再解析の重複操作を抑制する。
- タグを選択・解除でき、検索0件から条件解除で戻れる。
- 状態ラベルは色に加え文字を持つ。スマートフォンのメニュー開閉も動作した。

## 実操作で確認した範囲

- 専用アカウントでのログイン、テンプレート選択、Clipboard APIのコピー成功。
- AI出力空入力のエラー、架空出力のTurbo更新、解析後見出しへのフォーカス。
- タグの追加、カード保存、理解度「だいたい理解」・重要度「高」の保存。
- 次回復習日2026-11-02の設定。
- 検索候補の表示、ArrowDown→Enterでの候補選択、検索結果1件と0件。
- 観察したセッションのConsoleにwarn/error記録なし。全画面や全状態の無エラーを保証するものではない。

## 未確認・制限

- 外部AIサービスでの実際の生成は行わず、固定の架空出力を使用。
- コピー失敗、通信障害、形式崩れ、保存失敗、二重送信の全ケースは今回実操作していない。
- 他ユーザーIDへの不正アクセス、実際の「復習した」更新、削除・退会、Markdownダウンロードは未操作。
- テンプレート一覧のモバイル単独撮影、認証・ダッシュボード等の全主要画面撮影は未実施。今回の共通部品仕様を#130で展開する。
- スマートフォン実機、ソフトウェアキーボード、画面読み上げ、200%文字拡大の実機確認は未実施。
- 画像だけでコントラスト・タブ順・アクセシビリティ適合を断定しない。
- 06〜10など一部画像には操作時のスキップリンク／フォーカス表示が写っている。自動操作時のフォーカス状態を含むため、常時表示の不具合とは判断しない。
